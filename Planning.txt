INNOBRIDGE AI – FRONTEND QUICK REFERENCE (CURRENT VERSION)

---

1. TECH STACK

---

* Tailwind CSS → all styling done via utility classes
* Vanilla JS → handles interactivity (login, password toggle, spinner)

---

2. PAGE STRUCTURE

---

HTML Layout:

* Head → CSS + JS
* Body → full screen flex container
* Centered card → main UI component
* Inside card:

  * Title
  * Inputs
  * Options
  * Button

---

3. CORE UI ELEMENTS

---

A. Background

* Gradient: black → gray → black
* Full screen height
* Centered using flexbox

B. Glass Card (Main Container)

* Semi-transparent background
* Blur effect (glassmorphism)
* Rounded corners (rounded-3xl)
* Shadow + border

C. Typography

* Heading: large, spaced letters
* Subtext: low opacity
* No fixed typography system

D. Input Fields

* Underline style (border-b-2)
* Transparent background
* Focus highlight (border color change)
* Icon inside input (absolute positioning)

E. Buttons

* White background, black text
* Rounded, bold
* Hover + click animation (scale)

F. Spinner

* Hidden by default
* Appears on login
* Uses animate-spin

G. Checkbox + Links

* Basic styling
* Minimal interaction

---

4. JAVASCRIPT LOGIC

---

A. Password Toggle

* Switch input type (password ↔ text)

B. Login Flow

* Click button
* Show spinner
* Simulate delay
* (No real validation or API)

---

5. USER FLOW (LOGIN PAGE)

---

User opens page
→ Sees centered login card
→ Enters username/password
→ Optional:

* Toggle password
* Click remember me
  → Click login
  → Spinner appears
